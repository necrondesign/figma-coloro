# coloro

Показывает, что в макетах Figma сделано по дизайн-системе, а что мимо неё, и ведёт прямо
на слой, который надо поправить. Работает с любыми файлами и любой дизайн-системой.

[English version](README.md)

## Что умеет

**Проекты.** У каждого продукта свой проект: свои файлы, свой справочник токенов, своя история.
Проекты не смешиваются, а один и тот же файл можно добавить в несколько.

Интерфейс — три плавающие панели: слева проект и файлы (галочка — учитывать файл, клик по
названию — только этот файл, у каждого файла — обновить, открыть в Figma, страницы), справа —
что смотреть и что учитывать, посередине — выдача и поиск. Панели сворачиваются в кнопки, на
которых видны прогресс загрузки и ошибки; на узком экране они открываются окнами поверх.

**Сводка в каждом разделе.** Цвета, типографика, тексты, отступы, эффекты, картинки и компоненты
начинаются со своей сводки: главные числа со стрелками с прошлого обновления, рекомендации по
порядку пользы с кнопкой «показать эти места», файлы, где хуже всего, и график «как менялось».

**Общая картина в отчёте.** Главный экран: сколько цвета идёт через токены и стили, сколько левых цветов,
текстов без стиля, отступов мимо шкалы, безымянных кадров. Ниже — карта «файлы × проблемы»:
сначала файлы, где хуже, цвет ячейки — хорошо, есть что поправить, плохо. Клик по ячейке
ведёт к самим местам. Стрелки и график «как менялось» показывают, стало лучше или хуже.

**Цвета.** Все цвета, которые реально используются (сортировка по частоте, файлам, светлоте или
семейству, отбор по семейству, поиск по hex, токену и файлу), с делением на то, что с ними делать:
- *почти токен* — на вид не отличить, заменить на токен;
- *другая прозрачность* — цвет токена, но с иной прозрачностью: нужен токен этой прозрачности;
- *мимо системы* — далеко от всех токенов: добавить в систему или заменить;
- *не привязаны* — значение токена набрано вручную: привязать, внешне ничего не изменится.

Разница цветов считается по CIEDE2000 — так, как её видит глаз. Рядом — **градиенты** как
рецепты (вид и стопы по порядку) и **токены**: какие токены справочника реально встречаются в
макетах, а какие ни разу. Переменные с темами (светлая, тёмная) показываются одной строкой со
значением в каждой теме, а цвета макетов можно сверять с конкретной темой.

**Поиск.** Одна строка сверху: текст — в любой форме слова и в любом порядке («купите монеты»
найдёт «Купить 100 монет») по надписям, названиям слоёв и названиям компонентов (тогда находятся
все их инстансы); рядом — ширина и высота с допуском и цвет с палитрой, пипеткой, прозрачностью и
допуском. Части складываются: «Купить» + 56 × 56 + розовый — именно такие кнопки. Результат —
экраны со счётом, по экрану — слои со ссылками и подробностями при наведении (размер, шрифт, цвета,
откуда цвет). Справа — фильтры по найденному со счётом: тип, компонент, свойства вариантов
(Size, State…), страница. Каждый список копируется со ссылками одной кнопкой — для задачи или
сообщения. Поиск живёт в адресе: его можно сохранить и переслать.

**Токены.** Отдельная страница-таблица, как окно переменных в Figma: коллекции вкладками, слева
группы по пути в имени, колонки — темы. Все токены справочника — цвета, числа, строки, типографика,
тени; у цветов и чисел — сколько раз значение встречается в макетах, неиспользуемые и набранные
вручную отмечены.

**Типографика.** Тексты без стиля против системы стилей: точно как стиль, почти стиль, мимо
системы — с пояснением, чего именно в системе нет.

**Отступы, скругления, обводки.** Числа против шкалы. Шкала берётся из значений, уже
привязанных к переменным, а если переменных нет — из привычной сетки (отступы кратны 4).

**Тени и эффекты.** Набранные вручную против стилей эффектов.

**Картинки.** Одна картинка во всех местах — одна строка, с превью: видны повторы и заглушки.

**Компоненты.** Где стоят, какие варианты, сколько изменено, какие кадры похожи на
отвязанные копии. По желанию — превью: Figma рисует каждый вариант, а свойства (Size, State…)
переключаются, как в Figma, с большим превью выбранного варианта и местами, где он стоит.

**Отчёт одним файлом.** HTML-страница без внешних файлов: переслать, приложить, распечатать.

Система стилей, шкала и эффекты выводятся из самих макетов. Справочник токенов цвета
загружается файлом: W3C Design Tokens, Tokens Studio, выгрузка переменных или CSV любой формы.

## Как запустить

Нужен Python 3.9 или новее — встроенный в macOS подходит. Больше ничего ставить не нужно.

```bash
python3 -m coloro serve
```

Откроется браузер. Дальше:

1. **Шестерёнка (Settings)** — вставить токен Figma (Figma → Settings → Security → Personal access
   tokens, права на чтение файлов) и, если есть, файл со справочником токенов проекта.
2. **+ в левой панели (Add file)** — вставить ссылку на файл. Можно ограничить страницы по словам
   в названии. Новый проект — в меню проекта сверху слева.
3. **Update.** Первая загрузка большого файла — несколько минут, повторная без изменений —
   секунды: coloro спрашивает у Figma только версию файла и качает лишь изменившиеся страницы.

Токен можно не вводить в интерфейсе, а положить в `~/.config/coloro/token` или в переменную
окружения `FIGMA_TOKEN`.

Из терминала:

```bash
python3 -m coloro load "https://www.figma.com/design/…" --pages stage
```

```bash
python3 -m coloro stats
```

## Фильтры

Загрузка хранит всё: скрытые слои, архивные страницы, служебные секции — с метками. Что
учитывать, решают фильтры при просмотре, и они одни на все экраны, поэтому числа всегда
сходятся. По умолчанию считается то, что видно на экране:

| Фильтр | По умолчанию |
|---|---|
| Скрытые слои | не учитывать |
| Архивные страницы (archive, архив в названии) | не учитывать |
| Слои внутри компонентов | учитывать — они видны на экране |
| Страницы по названию | все |
| Секции по названию | ничего не исключено |
| Дата появления слоя | за всё время |

Тексты без стиля, отступы, эффекты и безымянные кадры считаются только у положенного на
экран вручную: внутри компонента их задаёт библиотека, и на экране их не исправить.

## Где данные

Всё лежит у вас на компьютере, в одном файле `~/.coloro/coloro.sqlite`. Ничего никуда не
отправляется, кроме запросов к Figma. Сервер слушает только `127.0.0.1` и не отвечает
запросам с других страниц. Токен хранится в `~/.config/coloro/token` с доступом только для
вас и обратно в интерфейс не отдаётся.

Удалить ссылку — значит удалить и её данные. Удалить всё — удалить файл базы.

## Масштаб

Проверено на 32 рабочих файлах разом — 4,3 млн слоёв:

| | |
|---|---|
| Загрузка всего | 20 минут, без сбоев |
| Повторное обновление без изменений | 8 секунд |
| Общая картина | 4 с при первом открытии, дальше мгновенно |
| Цвета | 1 с |
| Поиск текста и размера | 0,6 с |
